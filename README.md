## 怎么看 AI：三个视角、三个问题

AI 没有唯一本质，不同学科各取一个视角，合起来用三个互补的视角看它，每个视角回答一个问题：

| 视角 | 问的问题 | 对应篇章 |
|:---|:---|:---|
| 动力学（数学/物理） | 模型是怎么造出来的？ | 《AI数学》《扩散》 |
| 几何与表示（数学） | 造出来后，学到的知识长什么样、怎么组织？ | 《基座模型》 |
| 社会-工程（工程/社会） | 把 AI 放进真实世界，怎么从有用变好用？ | 《用好AI》 |

三个问题连成一条追问链——怎么造、造出什么、怎么用。《AI数学》→《基座模型》→《用好AI》是核心三步；《扩散》从《AI数学》出发，是"生成式塑形"这一条"怎么造"的深入分支；《AI law》把三条链里的"为什么符合规律、何时失效"收拢成一条规律支线（选读，前置《AI数学》《基座模型》）。

## 五篇文档 & 推荐阅读顺序

五篇文档独立可读，也构成"核心三步 + 两条选读分支"的路径。跨篇引用统一用简称：《AI数学》《扩散》《基座模型》《用好AI》《AI law》。

**核心路径（推荐按顺序读）**

1. **`1_ai_math/`** - AI数学：从起步到前沿（7 章 + 1 附录）
   数学工具链——梯度下降、拉格朗日、Softmax、反向传播、Attention、LoRA、MoE，为各篇奠基；第 7 章讲五场范式转移，收束到扩散。

2. **`2_foundation/`** - 基座模型：从咿呀到行动（6 章 + 2 附录）
   预训练与潜空间、SFT 与对齐起点、推理算力与 GRPO、RLHF/DPO/Safe RL、KV Cache 与全双工、VLA 与具身智能、世界模型六流派；"概念城市"专题讲潜空间可解释性与可干预性。第 2/3/6 章内分 Part A/B，便于按需深入。

3. **`3_use_ai/`** - 用好AI：从有用到好用（8 章 + 结语 + 4 附录）
   三站旅程：有用 → 可用（后训练四种反馈）→ 好用（Harness 六层 × 使用章法）。POMDP 眼镜、选型地图、控制范式、规划与 Skill 双刃性、四类失效、评估与护栏、多 Agent 协作（AgentFail 三层十三类）、自演化三路线；附录给出从十行代码到生产级 Harness 的实践路径与落地清单。

**选读分支（读完对应前置后按需深入）**

- **`1a_diffusion/`** - 扩散：从噪声生成（9 章 + 4 个附录）
   从"加噪声"出发一步步推导 SDE/ODE 框架、条件控制、离散扩散，收束到视频生成、世界模型与扩散策略；结尾用"技法 × 工具"框架统一前沿变体（DiT、流匹配、一致性模型等）。

- **`4_ai_law/`** - AI law：从现象到规律（8 章 + 4 个附录）
   回答"深度学习为什么符合规律、规律何时失效"。三拍组织：**看**（现象与动力学——双下降、grokking、涌现）、**懂**（可外推规律与机制——尺度定律）、**判与望**（五类失效边界 + 理论之梯回望章）。

## 自检怎么用

每章末尾有"本章自检"，提示与答案的位置随产物而异：

- **HTML（主产品）**：提示与答案以折叠块放在各题旁，先独立作答、需要时再点开；
- **DOCX（参考副本）**：提示保留在题目区，答案集中在文末，保持"先作答、再翻页对照"的隔离。

用法三步：① 先独立作答（回想或默写），卡住再看提示——提示只给方向；② 对照答案，句末 §X.Y 即回看正文的位置；③ 自检有五种题型（知识点/逻辑链/迁移/边界/生成），生成题答案自带"核对你的答案"清单。

## 生成发布产物

**普通阅读不需要构建**：`html/index.html` 已随仓库提供。以下命令供维护者重新生成。

依赖安装：`python3 -m pip install -r requirements.txt`（`pandoc` 需另行安装）。

### 最终 HTML（主产品）

```bash
python3 build_html.py    # 输出 html/index.html
```

> 若仓库中缺 `vendor/`，脚本会自动通过 npm 安装 KaTeX/highlight.js（需 Node.js 和网络）。

### DOCX 参考副本

```bash
python3 build_docx.py               # 生成全部 DOCX 到 docs/
python3 build_docx.py --verify-only
```
