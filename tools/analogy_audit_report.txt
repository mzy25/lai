# 类比/比喻审查报告（2026-08，C-D 子项）

## 结论
五书中**无"内容级重复类比"需删除/合并的实锤**。高频意象均属三类设计性用法：
1. **签名主比喻**（每书 1-3 个，作为教学记忆锚反复出现，属设计）：
   - AI数学：迷雾下山 / 碗 / 会诊室（Attention、多头） / 巨型图书馆（低秩） / 镣铐跳舞（拉格朗日）
   - 扩散：墨滴入水（主比喻，章首一次+回望引用）/ 地图缩放（多噪声水平）
   - 基座：万能草稿纸（潜空间心法系列）/ 一个 token 的旅程
   - 用好AI：毛坯→工具（后训练）/ 加工链 / Harness 眼镜（POMDP 章节系列）
   - AI law：论点集中于机制与规律，比喻最少（直引类比仅 9 行），符合"图鉴"文体
2. **递进扩展**（同一意象由单→多、由引入→破除误解，职能不同）：
   - 会诊室：ch5.1 单会诊室引入 Attention → ch5.6 多头=多会诊室并行（L1736/L2099）
   - 图书馆：§6.1 首现"低秩=上亿本书类型很少"（L2485）→ 附录误解五用"图书馆运营分工"讲 LoRA/MLA/DSA/CSA 组合（L3139）
3. **跨书复用**（独立可读需要，不同概念，不同意象语境）：
   - "读过整个图书馆的人"（用好AI 毛坯）vs "巨型图书馆分类"（AI数学 低秩）——不同所指，保留
