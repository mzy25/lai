# §21 这一切能走多远？——世界模型、认知与开放问题 ▽◇

语言模型预测下一个词；世界模型预测下一个世界。世界模型是最大的开放问题；开放问题清单与全书回收之后，还剩一个更难的问题：机器有没有意识——再往下追一层，是模型有没有认知，它知道什么、知道自己知道几分。

## 世界模型：一半是预测，一半不确定

世界模型是“给定当前状态和动作，预测下一状态或观测”的模型。“做完动作、世界怎么变”——这个转变叫状态转移；世界模型问的正是它：这个转变能不能被模型学出来。流派有六家：像素生成派（也叫生成派）、潜空间预测派（也叫 JEPA 派，Joint Embedding Predictive Architecture，联合嵌入预测架构）、混合派（兼取像素与潜空间）、符号派（靠规则）、神经辐射派（用三维连续表示）、世界模拟器派（把规则与外观一起学）；六家不在同一根轴上，不分高下，真正在较劲的是前两家。

生成派学的是完整分布：给定现在的状态和动作，下一帧的像素全都学。好处是能 rollout：把预测一步步推下去，从一张图推出整段视频，从一段视频推出物理上连贯的后续。JEPA 派只学表示：世界大部分不可预测，目标表示里可以丢弃的细节更多，损失落在潜空间，不生成像素。世界模型不一定是“会画视频的模型”：画视频只是 rollout 的一种形式。能 rollout 也不等于能规划：从预测到行动，还差动作空间和评估器两件（动作空间见 §15/§20，评估器见 §19）。

世界模型在具身智能里有四条用法，别混成一件事：

- 规划与控制：V-JEPA 2-AC（2026）的潜空间规划；Dreamer 一系的 model-based RL（先学环境模型，再用它训练策略）。
- 训练环境：Genie 3 生成可交互世界，让 Agent 在里面训练。
- 合成数据与 sim-to-real：Cosmos 的 Transfer/Predict 分支。
- 评估：用世界模型做可重复的测试环境。

四条线各有各的瓶颈：规划受限于动作空间与评估器，训练环境受限于动作空间与一致性（生成的世界逛得越久，越容易前后穿帮），合成数据受限于物理真实度，评估受限于覆盖度。生成一帧（或一个可交互环境）与“把生成模型放进规划器反复采样”是两回事：前者可以实时，后者才是分钟级的那档。

四条用法，四种瓶颈。

## 生成派与 JEPA 派：分歧在损失空间

| | 生成派 | JEPA 派 |
| --- | --- | --- |
| 现状 | 扩散与流匹配能 rollout 出难辨真假的视频；生成侧的四项关键技术：混合架构对长序列比全注意力更经济、MoE 稀疏激活省算力、测试时算力按难度调、扩散当统一框架（MoE 见 §6；混合架构、测试时算力见 §9；扩散见 T4） | 线性探针的成绩与监督学习同量级，算力约省一个数量级（论文口径）；阵营分三股：Meta 系、LeCun 创业系、第三方跨域扩展；跨域工作从视觉试到天气等七个领域 |
| 机制 | 学 p（下一帧）的完整分布，损失逐像素压 | 潜空间预测表示，纲领论证“部分不可预测、细节可丢弃” |
| 取舍 | 算力贵：像素生成路线（论文对照的 Cosmos 一支）规划一步要分钟级（论文口径） | 复现有争议：动作排序遭独立审计质疑、高频重规划会掩盖（这笔账 §20 动作路线节记过）；跨域增益不均匀 |

两派之争的关键在于，双方不换基础组件。用的都是 transformer，注意力一个不少；表里的“线性探针”是 linear probe；attentive probe 只是把读出换成 cross-attention（用一组表示查询另一组），也不是新组件。争的不是组件，是损失落在哪个空间：像素空间还是潜空间。

潜空间里的这笔损失，具体这样算。训练像遮盖填空：把画面遮住一块，模型先把留下的部分变成表示（表示＝中间层对一个输入的全部激活，§13 立过），**预测器**据此算出被遮那块该有的表示。标准答案由**目标编码器**给出：被遮块先经它编码成一串数。它的参数不接收梯度更新，只按慢节拍跟住正在学的这一侧——EMA，§2 给 Adam 估矩用的手法（新数＝大部分旧数＋小份新数）。损失，就是预测器算出的那串数与目标编码器给出的那串数之间的距离。答案那一侧为什么不跟着学？两边一起调整时，最省事的解是把所有输入都映射成同一串数：预测永远对、损失归零，表示却废了，行话叫**表示坍塌**。目标编码器不接收梯度、只按慢节拍跟住，预测器追的答案不随它自己变，这条近路就断了。

理论正在跟上实验：给嵌入分布定可证目标的工作（把防坍塌从工程惯例变成数学保证），和把两派的训练目标写成同一笔账、给两派搭桥的工作，都出来了——桥已出现，胜负未决。

JEPA 派也开始有账可算了：RoboJEPA 让机器人的潜空间世界模型第一次有了自己的幂律——前向预测误差随训练算力下降，拟合范围外仍能外推，误差还能提前预告真机规划的成功率（Zholus 等 2026，arXiv:2610.10515；代码与权重已开源）。语言这一路也有进展：把 JEPA 式的正则项加在下一词预测上（Semantic Tube Prediction，STP），十六分之一的微调数据就匹配了全量微调的准确率（Huang 等 2026，arXiv:2602.22617；ICML 2026）。这个数出自微调实验：1B–8B 的模型、固定的几套题。

JEPA-Anything 把同一套潜空间预测原则用到了物理上（Cui 等 2026，arXiv:2609.20800；代码已开源）。它从数据里恢复出开普勒第三定律：轨道越远，转得越慢——频率随半长轴（轨道的大小）按 −3/2 次幂下降；拟合出的斜率是 −1.4991，与定律的 −1.5 只差 0.06%。另一个经典控制任务上一次干预预测的误差也降了三成半。

## 开放问题清单

剩下的开放问题归成一串，每条只给定位，不给结论：

| 问题 | 定位 |
| --- | --- |
| 统一理论有没有 | 信息论、优化与架构能不能合成一个框架 |
| 能力的起源 | 涌现是评估假象还是真机制；这个问题还没有定论 |
| 特征的可观测性 | §13 的解码算不算“真看见” |
| 世界模型 | 能不能从预测走到行动：动作空间与评估器（上半节） |
| 推理动力学 | 思维链是算力还是算法 |
| 边界能不能跨 | §14 判定的定理边界有没有松动的可能 |
| 自动科研的边界 | 文献、实验、写作都有工具在接手；“新颖性”能不能自动化、甚至能不能形式定义，还没有答案 |
| 权重空间编程 | LLM 直接读/写权重，能否成为审计与优化的新接口；2026-11 博客报告，Hugging Face 已重建复评其 Qwen 实验，仍待多团队验证（§13 前沿） |
| 机器有没有意识 | 功能能力可以和体验脱钩；自我报告不可靠、“怎么测”尚无共识（见“认知视角”节末的意识选读） |

**Epiplexity：可学结构。** Epiplexity 问的是：给定算力约束，一段信息里能提取的可学习结构有多少，剩下的是在该算力与学习算法下提取不出的部分，未必是噪声。香农熵是不限算力时的极限特例；时间受限熵（给定算力/时间预算下的熵）才是现实口径。对预训练有四个待检验的启示：挑可学结构密的数据；按 Epiplexity 排课程；用合成数据（加真实锚点、过验证）增加它；让自主学习追着边际 Epiplexity 走。和 §9 测试时算力、§14 数据墙互为表里。这是前沿理论，证据还在初期。

**自动科研。** 自动科研那条线，处理对象是“想法”本身：结构化表示、跨域检索、对抗性检验、实验反馈持续修正。四个环节都有工具在做，闭环还没接成。IdeaScientist（Liu 等 2026，arXiv:2610.04074）把论文拆成问题、挑战、缺口、直觉、提案五元组，建成 277 万条的 Idea Vault（想法库）；检索限 2026-01-01 截点前文献，训练用截点后一部分，剩余留作评测——看系统能不能赶在人类发表之前推断出方向。作者列出的局限里有一条：模型参数里的记忆未受控（训练数据可能被记住）。能不能合上，还得看验证这一环：判对错贵不贵，评估器写不写得出来。

## 回收：维度、层次与地图

整套读物用五个维度回收，合称五维回收框：知识（会什么）、思路（怎么判）、直觉（像什么）、技能（能做什么）、理论深度（讲到形式层哪一层）。下表各举一例。

| 维度 | 它在哪里建成 | 一句话 |
| --- | --- | --- |
| 知识 | §9 生成与推理服务 | 自回归、采样、推理服务构成“会什么”的基础 |
| 思路 | §2 梯度下降＋§4 分摊 | 梯度怎么更新、误差怎么摊，判断的起点 |
| 直觉 | §0.1 的起步直觉 | 参数、损失、梯度构成开篇的直觉 |
| 技能 | 动手项目 | 走查、跑通、改造，多数章有实操口 |
| 理论深度 | §8＋§11＋§13 结构脉络 | 对称、谱、稀疏、低秩讲到形式层 |

**理论四类供给**：AI 跟理论的账，落在四件东西上，四类并列，不是递进层级。词汇这一类：信息论给了“信息”“熵”可算的定义（§3 的熵）。算法这一类：梯度下降与 Adam 在 §2，μP 在 §12，梯度怎么算归 §4。结构这一类：对称、谱、低秩主要在 §8、§11 展开，稀疏在 §13；§12 把谱搬到了数据侧。表达这一类：形式语言、电路、代数的表达力问题（§14 六类边界表的表达力行，与可计算性相邻）。理论不是摆设：每一处衔接，它都供给可查的工具与判据。

四类供给的账也说清：理论有时滞后于实践，先有做法、后有解释；有时又先行几十年——熵 1948 年就有定义，等到语言模型才迎来主战场。两面互相供给：理论给词汇、实践给现象，AI 也在回赠理论新问题。理论不取代实践，两边各自发展。

**两张回收地图**：低秩与谱这条线，§8 SVD 拆解，§11 奇异值有顺序，§12 把谱搬到数据信号、用截断算偏差，§14 技能分解收尾。技法与统一视角这条线，§2 梯度下降，§3 熵；T3/T4 把密度分数学习与采样加速并成一族，到扩散这条支线收束。密度分数匹配把朗之万采样接回 §2 的梯度下降，ODE 三源误差在 T3 提出、T4 回收。

还有七条线，把不同章的同一族主题串起来；其中谱线就是第一张地图，第二张地图不单列一行。它们不是新概念，是同一族主题在不同章的回声；每行内部仍可能含多个子问题。

## 认知视角：模型知道什么、知道自己知道几分 ▽

开放问题清单里，“机器有没有意识”这一问要往下再追一层：行为背后有没有“认知”——模型知道什么、知道自己知道几分。这一问没有结论，只有一套读法和三件做得到的事。

同一个“它好像知道”的主张，证据可以落在三层：

| 证据层 | 怎么拿到 | 长处与短板 |
| --- | --- | --- |
| 行为层 | 只看进出，系统当黑盒 | 谁都能测、能和人对表；同一份答卷可能出自真本事，也可能出自背过的题与题型上的巧合 |
| 表示层 | 读内部：这份信息在不在（线性探针一类手法，§13） | 能验证“信息在场”；探针可能自己把任务练会，读得出不等于会用 |
| 机制层 | 动内部，看行为变不变（§13 的激活修补与激活引导） | 证据最强，也最稀；要权重、要窄任务 |

目前，认知类主张的证据分布很不均：行为层独大；表示层与机制层的读数基本还只在裸模型（不带 Harness/Agent 外壳的基座模型）上见到，智能体身上更是几乎只有行为层。读法是：行为层通过只是起点，接上表示层、机制层，才算把“测的是那个东西”确认下来。这正是构念效度问题：测到，未必拥有。

三件做得到的事：校准、内省、外化（把要用的搬到系统外面）。

**校准**（confidence calibration）：报出的信心，和实际正确率对不对得上。前文几处“校准”多指评判员；§18 的“校准拒绝”是另一义；这一笔校准模型自己的答案。这一件有真读数：模型对自己“知道什么”，判断得相当准。多项选择题上，它给出的置信分数和正确率对得上；专门练过之后，还能在没看到选项时预判“这题我答不答得上”（Kadavath 等 2022）。三条限定：校准好坏随任务、领域、模型而变。用人类反馈做后训练，会动这份校准：奖励模型给自信的回答打分更高，有读数说它变差，也有读数说它变好。问法本身也进结果：口头报的信心与内部概率不是一回事，用 0–100 分打分报出来的信心，普遍偏自信（Xiong 等 2024）。操作含义：把口头信心当线索，不当证据；要实证，就自己抽样、自己过账。

**内省**：模型对自己内部状态的报告，有没有超出外人从行为里能推断的东西？证据是混杂的，两头都有硬读数。一头是“多出来一点”：一项实验里，模型预测自己在假设情境下的行为，比另一个用它的行为数据训出来的模型更准。这像是多读到了一点内部信息（Binder 等 2025）。另一头，让它自报对语言的判断：它自报自家内部概率，并不比它判断别的模型的内部概率更准（Song 等 2025）。更直接的因果证据是：用激活引导把“全大写”这类概念的方向注入内部，它在部分实验里能说出“有个过于强烈、音量很大的概念”（Lindsey 2025）。而轮到解释自己，就换成事后编理由：题面里的答案总出现在第一个位置，模型的选择跟着这个位置走，推理链里却只字不提这个手脚，理由编得照样顺（Turpin 等 2023）。这个毛病，人类也有：为自己说不清来历的选择，编出条理分明的理由（Nisbett 与 Wilson 1977）。操作含义：自述可以听，不能当证词；要证据，得另起一层去验。

**外化**：前两件都在问“模型内里靠不靠得住”；外化把方向掉转过来——与其等它内省，不如把要用的搬到外面。状态存成外部记录、随时更新；该做的检查落成一步步的验证动作；记忆从模型里搬进系统、多方共用。哲学里早有一个说法对应：总在手边、可靠查阅的笔记本，也算认知系统的一部分（延展心智，Clark 与 Chalmers，1998）。智能体架构正在照这个思路设计；顺带的好处是透明：挪出来的东西看得见、查得动、改得掉。§16 的记忆分层就是它的工程形态。前两件说明模型内里难测，第三件给出方向：**认知外移到系统**。

<summary>◌ 意识：最远的一问，两头的错都贵</summary>

Chalmers 2023 年把正反两面的理由都过了一遍。按他的判据，当前模型缺的东西成串——生物性、感官、身体、世界模型与自我模型（这两样已在进展中）、递归处理、全局工作空间、统一的主体。这些是候选条件，不是公认的必要条件。他给的估计是：当前语言模型有意识的可能性不到一成；“扩展之后的继承者”，高得多。

两个方向的错都贵。高估的代价已经在发生：把功能上的热闹当成体验在场，情感依赖、错付信任、被操纵会跟着来。低估的代价同样存在。若系统真有某种程度的体验，而我们一律当工具，那是大规模的道德错误。自我报告在这个问题上不能当证词：语料里满是“我有感觉”式的句子，扮演角色对它来说又太容易。所以现在能交付的只有诚实的不确定：理论没有共识，测法没有共识，“怎么算测到”更没有。能先做的不是判断，是两头各走一步：高估那头，把系统设计成不容易让人过度归因的样子；低估那头，模型福利的评估已经起步（截至 2026 年 10 月）。

</details>

## 收束

全书收在这里，基座、系统、自演化各管一段：基座定原生能力的上限，系统保稳定性的下限，自演化定持续增长的空间——缺一件，另外两件都替不了它。

能力栈最后落在应变与行动两个方向；外置（写进上下文）、内化（写进权重）、自演化三步走完，系统开始具备持续更新的形态。但能走多远，至少由三条硬边界决定：技能库漂移（§19 的 Library Drift）、容量无界、泛化间隙；容量无界，指自我修改越过可学习性极限。

§0.1 那张表的前三篇各问一个问题：能力怎样获得；能力为什么可信、何时失效；怎样用成可靠的系统。前三问都答过一遍：获得，靠梯度下降把通用表示写进权重；可信，看在边界之内还是之外——定理带前提、经验边界可挪；可靠，靠模型之外的工程系统（Harness、契约、护栏）。

3. （§21）收束的三项——基座、系统、自演化——各管什么？
4. （§15）七元组由哪七个部件组成，为什么状态要靠“猜”？
5. （§16）更强的模型为什么还是替代不了模型之外这一套？
6. （§13/§17/§19）拒绝方向、间接提示注入、跨 Agent 交接，为什么说是同一道边界？
7. （§17）四种控制范式沿哪根轴排开？

## 深究：给一篇论文定证据档位 ◌

结业项目四你已按证据档位读过一篇工程论文；这里换理论靶材再做一遍——从候选清单里挑一篇论文，或自己另选一篇，按六类边界表那种证据档位给它定档。按三项写：它属于哪一档（定理级、工程现实、条件性上界）、限制条件是什么、它对三个关注面（现状、机制、取舍）里哪一处贡献增量。交付一页证据卡：论文、证据档位、限制、落点。验收：档位指得回六类边界表；不停留在“听说过”。这道题用的就是可验证性剃刀：验证越便宜，进展越快。
