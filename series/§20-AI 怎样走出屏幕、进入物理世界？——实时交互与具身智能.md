# §20 AI 怎样走出屏幕、进入物理世界？——实时交互与具身智能 ▽

模型走出屏幕，跟实时的人和真实的机器打交道。先看实时：对话要快、要能插嘴、要能委托；再看具身：同一套表示怎么接到电机上。KV 账、三标配拆显存与延迟两道墙，流式只遮延迟墙的可见部分，总时长另算；延迟这一侧先谈。能力栈在这里接到两个出口：听和说是应变，动作是行动；萃取、筑基、炼灵三层，依次对应表示、预训练、后训练。

## 延迟拉平之后，看什么区分三种架构

对话系统有三种架构。第一种是级联式，把整条链拆开：语音识别转文本、大模型出文本、合成读出声音，三个模型串行。延迟可以一段一段算：语音识别、模型首 token、合成三段相加；现在能压进 300ms 内，早期要高得多。另一笔损失藏在转接里：语气、停顿、背景音、说话人特征，每过一跳就少一点。

第二种是回合制，单模型音频进音频出。麻烦出在判定"说完了"的那个模块（VAD，语音活动检测）：静音超过 500ms（示例值）就轮到模型。人思考时的停顿约 600ms、深呼吸约 700ms（同为示例值）、噪声间隙也不规则，模型常常抢答，或者被一声咳嗽切断。

第三种是全双工，连续处理输入的同时持续生成，不把对话切成回合。它带来三样能力。持续交互，每秒约十次地决定说、继续听、暂停、还是打断；自然应答，"嗯嗯"这类应答由模型自己决定时机，而不是等用户说完；委托，深度任务扔给后台，前台继续聊。这里每秒十次是量级估算，由公开需求反推，不是某家产品的实测。

把三种架构摆在一起看，模型出首个音频包的延迟已经拉平——级联压进 300ms 内、回合制 300–500ms、全双工也在 500ms 以下（截至 2026 年 10 月）。回合制的这笔账不含 VAD 等静音的 500ms；端到端要把那一段另加。速度不再是唯一区分维度，现在看两个维度：可打断性（模型说话时用户插嘴，接不接得住）和主动应答（用户话没说完，模型敢不敢应）。选型时还有第三条：工程复杂度——级联老而不过时，定制音色、多语种、客服与审计这类场景仍然是它的地盘，选型是取舍不是代际更替。

## 真委托的三道测试

全双工把深度思考挪到了后台，架构随之分成两层：交互层管实时对话（用户感知的延迟压在 500ms 内），推理层管深度推理（数秒级）。两层并行，前台话头一直占着，用户感觉不到"在等"。这是发布材料口径，不是逐项实测。

委托的真假，测三样。打断测试：用户插嘴时，后台任务是否保持，回来还能不能对上话头。双通道测试：对话与后台执行是否真的并行，用户问进度时能不能答出阶段。延迟分布测试：不看平均延迟，看首响应延迟的长尾。三样都过，才叫委托；只把任务推给后台，那叫假委托。

## 会描述不等于会执行

视觉语言模型懂场景、会描述，让它抓起杯子还要过一关。第 15 章讲过感知的难（部分可观测）；动作的难另有两条：动作空间是连续的（关节角是连续值，不是一个一个的档位），评估只能看结果（抓没抓到，无法用语言校验）。

具身的核心是 VLA（Vision-Language-Action）：把视觉、语言、动作塞进同一个模型，输出直接是电机指令。"会描述不等于会执行，换的是出口，不是表示本身。"

## 动作的三条路线

第一条把连续动作离散成 token。做法是把每个关节的取值范围切成若干区间。看 RT-2 的具体数字：七个自由度的机械臂，每维从 −π 到 π 均分 256 份，每份宽 0.0245 弧度、约 1.4 度；模型像说话一样逐步预测动作 token，一次规划 4 步就是 28 个 token。离散化的代价是量化误差：相邻区间中点之间总有缝，最坏落在半个区间宽、约 0.012 弧度。这个精度够不够，不看数字看任务。

第二条用连续策略直接学分布。flow matching 让模型输出高频连续动作块，天然是多峰的（同一个局面有两种合理抓法，就不必压成一种）。π0 是这条路线的一个代表工作：它把 flow matching 用作 VLA 策略，也属于跨形态通用策略方向。一张延迟分解表，看清端到端意味着什么。一套常见配置，从摄像头读出到力反馈就绪，各段耗时约如下（工程估计）：

| 段 | 耗时 |
| --- | --- |
| 摄像头读出 | 33ms |
| 图像信号处理 | 5ms |
| 视觉编码 | 10ms |
| 连接器 | 2ms |
| 模型前向 | 80ms |
| 采样解码 | 约 8ms |
| 电机执行 | 50ms |
| 力反馈 | 1ms |

合计约 200ms。端到端指单一模型直接出动作，分层指高层慢规划加低层快执行；所谓"端到端 VLA 200ms、分层方案 2 秒"的差距不在零件快慢，在决策粒度：前者每 200ms 重想一段动作序列，后者每 2 秒重想一个子任务。

第三条路线把规划搬进潜空间。V-JEPA 2-AC 是这条路线的代表工作：用一百万小时互联网视频预训练出视频表征，再用不到 62 小时机器人视频做后训练，得到动作条件世界模型。规划不必逐像素合成未来，在潜空间里算轨迹就行。论文口径下，机器人每步规划约 16 秒（这是规划一步的耗时，与执行回路的毫秒级节拍不是一回事），而像素生成路线（论文对照的 Cosmos 一支）要 4 分钟，差约一个量级；零样本操作成功率约 65%–80%，任务不同差异大（均为论文口径）。它的复现争议（独立审计质疑动作排序，且高频重规划会掩盖该缺陷）见 §21。

选路线的判据三条：动作空间大小、频率要求、要不要可解释的 token 化接口。离散 token 的好处正在于第三条：接口干净，能被日志和测试直接读。

## Sim-to-Real：差距要显式建模

仿真里练的策略上真机要打折，这是仿真一侧与真机一侧各自撞上的同一堵墙。两项经典观察：一是域随机化有效：光照、纹理、相机参数随机化之后，策略学不到特定细节，反而能迁移；二是折扣真实存在：仿真再好，真机的物理、延迟、磨损都拿不完全。

一个案例讲透"隐形变量"：仿真里物体打光固定，真机上光照每帧都在变，策略干脆学了个光照捷径：认光照不认物体。表现是仿真里满分，真机上把影子当成抓取线索。所以 Sim-to-Real 不是"仿真白做"，是把仿真和现实之间的差距当显式变量：灯光要随机化、摩擦抽样、延迟合成，差别有多大，折扣就有多大。

物理安全另有一栏是力限制：接触力要限幅、碰撞检测要有响应链。与人体接触的力不能超 140N 量级，约等于一个手指顶住 14 公斤孩子的力；分部位许用值各不相同，做真机前按机器人安全规范查。物理世界的四条硬约束：不可逆、成本高、泛化难、安全刚性——这四条是"行动的出口"的硬边界。

## 能力栈收束：两个出口

能力栈在这里收束成两个出口：实时交互是"应变的出口"（听和说跟得上人和环境的变化），具身是"行动的出口"（动作直接改变物理世界）。两个出口共用同一套 Harness（模型之外的整套外部系统）：表示在内部，约束在外面——应变侧接的是延迟要求，行动侧接的正是那四条硬约束：不可逆、成本高、泛化难、安全刚性。第四节的三种做法，分属动作表示与规划两层：两条表示路线（离散 token／连续策略）＋一条规划路线（潜空间规划），各自面对那四条硬约束。全景见最后一章。

## 结业项目四：跑通一条语音回路

这个项目默认给语音方向的人，具身方向请做完上面三个项目再回来。任务是复现一个开源的全模态语音助手 MiniMind-O：下载权重，跑通命令行里的一句话英文问答。跑通之后，对照"延迟拉平之后"一节，记一次"输入到出声"的分段耗时：预处理、前向、解码、播放，各占多少。再写一段判断：全双工三能力里，这个项目做到了哪几样，还差哪几样。再挑一篇全双工论文，按 §14 六类边界表那种证据档位读一遍（读法见 §21）。模型约 1.15 亿参数、投影器百万级（截至 2026-10 快照）；CPU 可跑推理，七个示例问答约 1 分钟（本机实测 58 秒，记录见 assets/§20-体验实验/）。有 GPU 的可以把英文小数据集的两小时训练链路跑一遍（约两小时一张 3090（上游口径，本机未实测）；中文或视觉走完整数据集）。没 GPU 也不卡：前三个任务 CPU 足够，训练那步要租一张云端卡（按小时计，用完即停；计费口径同 §0.3）。
