# 环境指南

> 零外部链接：笔记本都在本书资产目录里，用「下载 → 上传 Colab」两步走。页脚标着本页最后一次环境核验的日期；重核后请更新它。

## 怎么选运行环境

| 你的情况 | 怎么办 |
| --- | --- |
| 只有浏览器 | Colab（浏览器里的云端算力，免费档够用）：把对应章的预置笔记本下载到本机，再上传到 Colab 打开，逐格运行 |
| 一台普通电脑 | 本地 Python 3.11 以上：建虚拟环境，按笔记本首格列出的依赖安装；玩具实验与小模型都跑得动 |
| 自带显卡（8G 显存以上） | 同上，本地跑更快；§7/§8 的 7B 完整训练仍需更大显存或租卡 |
| 愿意云端租卡 | 结业项目里 7B 微调的完整训练按小时租卡，用完即停；§20 的两小时训练链路同理 |

## 笔记本在哪

每章动手节的预置笔记本在 `assets/§N-体验实验/` 目录下；本页末尾按章列出全部笔记本与实验目录。

T1–T4 与 §16 这类没有笔记本的单元：脚本与运行记录同在对应 `assets/…-体验实验/` 目录里（如 `assets/T3-体验实验/toy_diffusion_train.py`、`assets/§16-体验实验/station*.py`）。T3 训练循环脚本需要 numpy 与 torch（CPU 可跑）；§16 六站需要 `pip install smolagents`（目录里有 README）。

## Colab 两步

1. **下载**：在本页末尾（或章末资产卡）点进对应笔记本，用浏览器「另存为」保存到本机；
2. **上传**：打开 Colab → 文件 → 上传笔记本 → 逐格运行。免费档可能提示算力上限，隔一段时间再试即可。

## 六站小实验（§16–§17）

六站用本地 Python 即可，全程零 API key、约 100 分钟，不需要 GPU；跑法与检查点在 §16 与 §17 的动手节，资产在 `assets/§16-体验实验/`。
