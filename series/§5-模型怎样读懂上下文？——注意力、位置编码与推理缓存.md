# §5 模型怎样读懂上下文？——注意力、位置编码与推理缓存 ▽

墙砌完了，零件也齐了：分数怎么打，§3 的事；误差怎么分，§4 的事。上一章结尾留了一句话：接下来看这些零件怎样联成一台机器，"联"这个字得先分清。上一章的连接是参数之间的线：线上的权重，训练学到，推理时固定。本章的"联"是词与词之间的关联："苹果"在"吃苹果"里该多看看"吃"，在"苹果公司"里该多看看"公司"，关注谁取决于内容，没法预先固定。给词与词当场拉线，这一手的行话叫**注意力机制**，核心创新是**动态加权平均**：权重由输入现场算出，每读一句话都重排一遍。上一章结尾埋的几笔账（三个矩阵的梯度、归一化与门控的位置、Xavier 的方差守恒），本章逐笔兑付。

## 两种"联"——动态加权平均

先把两种"联"摆开看清。§0.1 立过的权重是模型的固有财产，训练收场时各是多少就是多少；而**注意力权重**正相反，由输入当场算出，同一对词换一段上下文就重新排队。它既不是参数，也不是一张给每对词预先定好亲疏的表：谁的权重多大，是输入进来后由学到的变换当场算出来的。

这个对照在前馈网络里有一面镜子：同位置内部逐维度门控，管特征筛选；注意力跨位置加权聚合，管信息聚合，一个筛自己，一个看别人。

画面换成一间会诊室：你的症状是**查询**（Query，首字母 Q），你在问该听谁的；每位专家的专长标签是**键**（Key，K），标明擅长什么；谁对症，谁的治疗方案就更被采纳，方案是**值**（Value，V），能贡献什么。最终诊断是所有专家按对症程度加权投票的结果，匹配过程动态重新计算：同样的专家阵容，换一个问题，注意力分配完全不同。

数字照旧从小开始。"猫吃鱼"切成 3 个 token（§1 主责），词表给编号，Embedding 查表（§1）换成数：每个 token 4 个数字，3 行摞起来就是输入矩阵 X(3×4)，行是 token，列是维度；这组数字是随便挑的，为了好算，算出的注意力分布不代表普遍规律。

这套机制又叫**自注意力**：查询、键、值从同一份输入投影而来，自己问自己。当代标准形式是一行公式，`Attention(Q,K,V) = softmax(QK^T/√d_k)V`，缩放点积注意力，Vaswani 等 2017 年提出。更早的加性注意力（Bahdanau 等 2015）已经把这套"按相关性加权"的思路用于翻译；Transformer 则换成了便于并行的缩放点积注意力。拆开只有两步：先用 Q 和 K 算匹配度，按内容相似度软寻址；再按匹配度对 V 加权提取。式子里的 d_k 是投影后的维度，下一节就用。

一个误解趁早说清："注意力就是加权平均，和池化差不多"。**池化**也是加权平均，但权重固定不变：平均池化永远各占 1/n，读什么输入都不变，而且是降维，把 n 个数压成 1 个。注意力的权重随输入当场重算，输出还是一个 token 一行，一个不少，变的是每行的内容被上下文重新丰富。一个压缩，一个沟通，形状像，干的事完全不同。

## Q、K、V：查询、键与值

### 前向：投影、打分与加权

同一个 X 走三遍投影：做三次矩阵乘法，分别乘 W_Q、W_K、W_V 三个投影矩阵，得 Q、K、V。**投影**是工程行话，指矩阵乘法 XW 把向量从 d 维变换到 d_k 维，这里从 4 维压到 2 维，d_k=2，小得只为手算方便。分工是：Q 负责提问，K 负责报专长，V 负责给建议。验一格：X 第一行 [0.1, 0.2, 0.3, 0.4] 乘 W_Q 第一列（脚本里是 [1, 0, 1, 0]），0.1×1 + 0.3×1 = 0.4，正是 Q 第一行第一列。三个矩阵全算出：Q=[[0.4,0.6],[1.2,1.4],[2.0,2.2]]，K=[[0.4,0.7],[1.2,1.9],[2.0,3.1]]，V=[[0.6,0.4],[1.4,1.2],[2.2,2.0]]。维度账很清爽：X(3×4) 乘 W(4×2) 得 3×2，内维 4 消去；3 行是 n=3 个 token，4 列是 d=4 维。

Q 的第 i 行与 K 的第 j 行做点积（对应位置相乘再相加，§4 的工具），得到第 i 个 token 对第 j 个的关注程度；九个数排成一个 3×3 的矩阵。验一格：第 1 行第 1 列 0.4×0.4 + 0.6×0.7 = 0.16+0.42 = 0.58。九格全算完：QK^T=[[0.58,1.62,2.66],[1.46,4.10,6.74],[2.34,6.58,10.82]]，数字肉眼可见地偏大，非除不可。

先猜一笔：d_k=64 时，Q、K 的元素方差各约 1，点积的标准差大概多少？64 个独立项方差相加，标准差约 8。这笔账 §4 欠着：Xavier 初始化把 W_Q 的元素方差设为 1/d，让 Q 的每个元素方差约为 1，与 d_k 无关的常数；于是 d_k 越大，点积方差越大，d_k=64 时分数散落在正负 20 开外，Softmax 把最大的推近 1、其余压近 0，输出几乎是 one-hot，梯度随之消失。除以 √d_k（64 开方得 8），方差压回约 1。Xavier 的方差守恒在注意力的缩放里再现，账清。

这个除法和 §3 温度里的 1/T 形式相似，来源和可调性不同：T 是拧得动的旋钮，管分布松紧；√d_k 由维度决定，不可调，管数值稳定。两个除法，别认成一个。除完得**匹配度分数**矩阵 `S=QK^T/√2`（√d_k=√2≈1.414）：S≈[[0.410,1.146,1.881],[1.032,2.899,4.766],[1.655,4.653,7.651]]。分数高，表示两个 token 朝向接近、内容相关。

分数只是原料，下一步变成权重。S 每行过一次 Softmax（§3 的机制，直接用）得**注意力权重矩阵** A：每行先减最大值（§3 排过的数值暗礁）再取指数、按行归一化。每行的和为 1：当前 token 的注意力预算被 100% 分配给所有 token。第一行立刻验算：减最大值 1.881 得 −1.471、−0.735、0，取指数约 0.2297、0.4793、1.000，合计 1.7091，除回去，得 [0.1344, 0.2805, 0.5851]。三行全出来：A=[[0.1344,0.2805,0.5851],[0.0203,0.1312,0.8485],[0.0024,0.0474,0.9502]]，每行和都是 1。三行分布迥异：第 1 行摊得最开，给第 3 个 token 最多（0.585）；第 3 行最集中，95% 给了自己。丑话说在前：第 3 个 token 最关注自己，是这组随手挑的数据的偶然，不是普遍规律。

最后按权重取回：输出矩阵 O=AV，O 的第 i 行是 V 的所有行按 A 的第 i 行加权求和。验一格：0.1344×0.6 + 0.2805×1.4 + 0.5851×2.2 = 0.0806+0.3927+1.2872 = 1.7606。完整结果 O=[[1.7606,1.5606],[2.0626,1.8626],[2.1583,1.9583]]。第一行明显向 V 的第 3 行偏移，因为第一个 token 的注意力里第三个占了 58.5%。至此，每个 token 的表示混入了它关注的那些 token 的信息。整套动作是"线性组合+非线性加权"的混合体：加权求和是线性的，权重过 Softmax，是非线性的。

### 反向：误差怎样分回 Q、K、V

四步正着走完，链式法则接着开工：误差怎么从 O 分回 Q、K、V，是上一章规矩的矩阵版本。记 g（g_ij）是损失对 A 的梯度的简写。第一程两式：损失对 A 的偏导 = 损失对 O 的偏导 · V 的转置，损失对 V 的偏导 = A 的转置 · 损失对 O 的偏导；维度匹配仍是金标准，(3×2)·(2×3) 得 (3×3)，(3×3)·(3×2) 得 (3×2)，恰是 A、V 各自的形状。

第二程穿过 Softmax，先认**雅可比矩阵**，一个装偏导数的方阵，(i,j) 位置是输出第 i 个分量对输入第 j 个分量的偏导；Softmax 的雅可比记 J，对角线元素 A_i(1−A_i) 恒正，非对角元素 −A_iA_j 恒负，提高一个注意力权重必然以降低其他权重为代价，数学上的零和博弈。落到每个分数上：`δ_S,ij = A_ij·(g_ij − ∑_k A_ik·g_ik)`，读作：该分数的梯度 = 该注意力权重 ×（外部梯度 − 同一行的加权平均梯度），零和结构原样传进梯度。

第三程回到 Q、K：损失对 Q 的偏导 = δ_S·K/√d_k，损失对 K 的偏导 = δ_S 的转置 · Q/√d_k；分母上的 √d_k 别丢，分数由 QK^T 除以它得来，链式法则要求它原样传进梯度。想再往前追到 W_Q，还需再乘一份 X 的转置。最后一个观察：Q 和 K 在分数里乘在一起，更新 W_Q 的依据含着 K 的当前状态，更新 W_K 的依据含着 Q 的当前状态，两个矩阵联动调节。

一个误解正好在这儿说清："Q、K、V 不都从同一个 X 来吗，为什么要三个不同的 W？"问得有理：强制三者相等，分数矩阵就只剩"谁和谁长得像"一种信息。三个投影自由分工：提问的角度、可匹配的特征、可传递的内容各管一摊，硬并成一股会限制表达，通常成绩更差。同一份病历，化验看指标、影像看形态、病史看病程：读的同一份，看的不是一回事。

### 位置：RoPE 把顺序写进点积

手算链走通了，还差位置：四步里没有一步用到 token 的顺序，输入任意打乱，输出跟着同等打乱——换的只是各行位置，数值一个不变，这叫作**置换等变**，"我打你"和"你打我"在它眼里毫无区别。位置必须有人告诉它。老办法是**位置编码**：给向量加一个位置向量，有效，但位置信号和语义信号挤在同一个向量里相加。**旋转位置编码**（RoPE，Su 等 2021）换思路：不加，转。每个 token 的 Q、K 各转一个由位置决定的角度，V 不动。

旋转用平面旋转矩阵 `R(α)=[[cosα,−sinα],[sinα,cosα]]`，α 是转过的角度。旋转只改朝向、不碰长度，语义强度原样保留，位置信息全放进朝向里，于是点积天然只看见两个 token 的朝向差，也就是相对位置：朝向差等于旋转频率乘相对距离；在半圈之内，距离越近，点积越大（越出半圈，余弦开始回头——见本节末尾的边界）。

每对维度配一个**旋转频率**，记 φ_i（读 phi-i，专指这里的旋转频率；它与 §4 的参数总名单 θ 无关，别认串）。token 的位置编号记 pos，转过的角度就是 pos×φ_i。手算照旧：取 15°，单位向量 [1,0] 从位置 0 到 3 转过 0°、15°、30°、45°，变成 [1.000,0.000]、[0.966,0.259]、[0.866,0.500]、[0.707,0.707]；点积只由角度差决定，等于夹角的余弦，差 0°、15°、30°、45°，内积依次 1.000、0.966、0.866、0.707。关键验证：位置 0 对 1、1 对 2、2 对 3，相对距离都是 1，内积都是 0.966。相对距离相同，内积就相同，注意力分数只依赖相对距离、不依赖绝对位置，这就是旋转位置编码的核心。

一把尺子只量得了一种尺度，那就多备几把。给不同维度对配不同频率：`φ_i = 10000^(−2i/d_k)`。换个稍大的假想头：d_k=8 时四对维度得 1.0、0.1、0.01、0.001（单位是弧度，上面手算的 15° 是角度，两个别混），大约分别在 2、16、157、1571 个位置的范围内灵敏（有效范围按 cos 从 1 降到 0 的距离折算），灵敏度范围差出近三个数量级。d_k/2 个频率像多把不同精度的尺子叠加：游标卡尺量毫米级，卷尺量米级，每把尺子负责自己擅长的尺度范围，距离 1 的细微差别归高频管，距离 500 的大格局归低频管。

收尾两句。先说边界：余弦是周期函数，注意力随距离呈周期性变化，不是单调衰减，周期性是编码的属性，不等于对任意距离的泛化保证；截至写作时点（2026-10），开源主流的大模型（LLaMA、Qwen、DeepSeek、Mistral）都把 RoPE 当默认配置。还有一处纠缠：有的新结构把 K、V 压成低维缓存，旋转编码却转不到压缩结果上，两者如何兼得，§8 再讲。

## 多头注意力：几种看法同时用

一种看法不够用。还是那间会诊室：同一批专家，多开几间，各看各的侧面。这里的"专家"指被咨询的 token，"会诊室"指并行的几套投影矩阵，各有各的 W_Q、W_K、W_V；多开一间会诊室，不是多请一批专家，词的名单一个没多。

**多头注意力**做的是：把各头的输出拼接起来，再乘一个融合矩阵 W_O 缝回原来的宽度。各行其事的依据叫**归纳偏置**，模型结构内置的假设，偏好学习什么样的模式。参数账摆出来：一个头用 d_k 维，头数记 n_h，n_h 个头总维度 `n_h×d_k=d`，和一个 d×d 的大矩阵参数量一模一样。那为什么不只用一个大矩阵？因为单个大矩阵只算一种注意力模式，多个小头各产生一种：一个头盯语法依赖（主谓一致），一个头找语义相似（同义词），一个头管相邻位置，最后 W_O 把互补的模式融合。实践里多个小头通常优于单个大头，训练后头与头学得多像，是另一笔账，§9 的效率回访再对。

多头注意力还能长出可命名的小电路。模型内部有一类"照猫画虎"的电路：见过 A→B 的模式，再遇 A 就预期 B；§6 讲 ICL 时会再提。这个电路叫**归纳头**（induction head），是**电路**（circuit）的第一个实例。所谓电路，就是模型内部一组可重复执行的子结构。这套电路由 Anthropic 的 Transformer 电路研究命名，2022 年的工作又刻画了它在训练中成批出现的动力学。它的做法配得上"照猫画虎"四个字：看到当前 token，先用查询 Q 与键 K 匹配，在上文里找到它出现过的位置，再用值 V 把那个位置的后一个 token 复制出来。Q、K、V 是上面那套分工：查询负责提问，键报专长，值给建议。匹配加复制，就是归纳。

这条电路可以被完整地搭出来：造一个注意力头，Q、K 设成"按 token 匹配"，V 设成"取后随 token"，在 a,b,a,b,c,e,c,e 这样的合成序列上，第二次出现的 a 和 c 预测后继，正确率 100%；注意力也确实落在 a 与 c 第一次出现的位置上。这是构造性示范，不是训练侧证据：参数是人给的，不是训练出来的。它证明这样的头能做匹配-复制，不证明训练长出来的头长这样。真实网络里，一条归纳头通常由两层合作：第一层先做出"上一个 token"的表示，第二层用匹配-复制完成预测。

训练动力学一侧，归纳头在训练中段突然成批出现，伴随 ICL 能力的跳升（2022 年论文口径，token 量在十亿到几十亿的窗口）。ICL 不止这一条路：至少还有任务学习与检索式机制（§13 展开）。

## 组装成 Block：现代模型的标准件

零件齐了，装机。一台现代语言模型说穿了：文字串变成向量序列，注意力和前馈网络一层层处理，再转回文字串，不新增任何数学工具，全是 §3、§4 和本章的。这台机器的标准件叫**基本块**（Block）：一台模型就是 N 个基本块叠起来，外加首尾两道工序。

整机走一遍，四步。第一步查表：每个 token 查 Embedding 得向量，那张表记号 E，输入编号，返回第 i 行，查表不是计算，是记忆。第二步处理：进基本块，"今"逐渐吸收上下文——出块时它已经是"今天"的"今"，不再是"今年"的"今"；每个位置都去上下文取回自己缺的语义。第三步打分：取末位置的向量 h_final，乘矩阵 W_head（**LM Head**，一张把隐状态摊成每个词分数的表），得分数 z，z 还是 §3 的 logits，过 Softmax 成概率，随手举例："很"0.31、"去"0.22、"的"0.15。第四步生成：按概率抽一个词接到序列末尾，从第一步再走一遍，这就是**自回归**（§0.2 报过名字），每产出一个词，全体重来。就这四步，循环往复，没有新数学。抽词的门道，温度怎么拧、候选怎么筛，§9 细算。

循环里藏着一个设计约定：生成只能用已知信息，不能偷看未来。落到注意力上是一道**因果遮罩**，写成矩阵 M：第 i 行第 j 列，j 比 i 大的位置填 −∞（第 1 行第 1 列是 0，可以看自己），Softmax 之后被遮处权重归零，只看左边。工程实现里 −∞ 用一个足够小的负数（如 −1e9）代替。双向编码器（BERT 那类，整句读完再下结论）不设这道遮罩，那是另一条路线，一句带过。

Block 不是只有注意力；两道子工序各配一个现代零件：激活与前馈，归一化与残差。先认激活与归一化。

**Swish** 是 x 乘 Sigmoid(x)，负数压缩但不归零；**SwiGLU** 拿它当门控，一条路算门、一条路算信号，逐元素相乘，在 LLaMA、DeepSeek 等主流开源模型里很常见（写作时点）。

家族里还有 GELU，GPT、BERT 就选的它，形状在负区先探到零下、再回升（一道浅凹），思路与 Swish 同路。

配套工程之一是**归一化**。前向手算里的特征缩放，就是一种归一化：让特征落在相近的数值范围，大数不在矩阵运算里压过小数。LayerNorm 把一层输出的每个数先减均值、再除标准差，调回均值为 0、标准差为 1 的分布，再用两个可学参数微调；现代大模型更爱用它的轻量版 **RMSNorm**：激活值的均值通常已接近 0，减均值这步收效甚微，省掉它，效果不分伯仲，LLaMA、DeepSeek、Mistral 都这么选。回想 §2 的 Adam：Adam 给步子分大小，归一化给信号定形状，互补，不互相替代。没有归一化，层层叠加之后信号的形状会一路漂移，深层的数要么太大要么太小；这笔账和 §4 的初始化记的是同一笔。

基本块内部两道子工序，各配一次归一化和一条**残差连接**。第一道：先 RMSNorm（上面刚认过的轻量归一化）把向量尺度校准到同一量级，再送注意力动态取回上下文，最后把结果加上原始输入。这"加上原来的"就是残差连接：注意力算得再差，模型也不致偏离原始信息太远；它还是一条不经过任何归一化的纯加法通道，梯度一路流回第一层，一百层也稳。

归一化排在注意力之前，这套排法叫 **Pre-Norm**；早期方案排在之后，深层里早期层的信息被归一化逐渐稀释，近输入的层几乎学不到东西。GPT-2 之后，Pre-Norm 成为主流大模型的默认排法。第二道：再过 RMSNorm，进**前馈网络**，再残差加回。前馈网络的主体是 SwiGLU，两层全连接，一条路算门、一条路算信号。分工就此落定：注意力查找关系，前馈网络注入知识，是模型存放静态知识的主要容器；研究里还有人把它的第一层叫键、第二层叫值，当成可编辑的记忆来解剖（Geva 等 2021）。每层先归一化，注意力动态整理语义，残差加回；再归一化，前馈网络注入静态知识，残差加回。N 层之后，每个词的信息经历了 N 次动态沟通和 N 次知识深化。

训练时，预测分布 p 和真实标签的交叉熵（§3）给出损失，链式法则把责任传回每个参数：Embedding、三个投影、前馈网络、W_head，同一套链式法则，只是路径更长了。拿一句话反复练的玩具模型最能看清循环：词表只有几个字符，这张嵌入表先冻住（真模型里它是 §4 追责过的参数，照样一起学），前向、打分、反向、更新四步转圈（玩具里只从末位算损失，省去显式遮罩；真模型按因果遮罩对所有位置并行算损失），初始损失是均匀瞎猜的 ln4≈1.386（四个候选各四分之一），转着转着，它把语料的循环模式记进参数，能一路续写下去。这个循环没引入任何新数学：§2 负责更新，§3 负责打分，§4 负责追责，本章负责看上下文——语言模型的"学习"，就是这四件事在同一循环里一遍又一遍地重复。

## KV Cache 原理（GQA/MQA 变体见 §9 的效率节）

训练是全体一起算，推理是一个词一个词往外蹦，两种节奏之间藏着一个省时机关。生成第 t 个词时，前 t−1 个词的 K 和 V 在前面每一步里都已算好，值不再变，何必重算？存下来复用，就是**推理缓存**，也就是 **KV Cache**。新词要算自己的 Q、K、V，K、V 追加进缓存；Q 和缓存里全部 K 点积，按权重对缓存里的 V 加权，完事。

这笔账：单层里，序列每多一个词，缓存多出 2×n_h×d_k 个数，K、V 各一份，每个头各一份。它占的是**显存**，显卡上读写飞快、容量金贵的内存，不是算力；缓存只省重复计算，不改数学结果，一个数都不差。工程上还把推理分两程：先一口气把整段输入算完，叫 prefill（预填充）；之后每出一个词只算增量，叫 decode（解码）。

另有一笔账先挂账：token 两两配对，序列长度变为原来的 k 倍，配对数变为 k² 倍，平方增长是要命处。还有一处观察：训练后的模型里，不少头学到的注意力模式高度相似，让它们共享同一份 K 和 V 岂不更省？这个方向叫 GQA、MQA（后者是共享到底的极端），变体细节和这几笔账，§9 的效率回访细对。
