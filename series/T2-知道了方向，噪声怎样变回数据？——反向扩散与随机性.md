# T2 知道了方向，噪声怎样变回数据？——反向扩散与随机性 ▽

上一章把清晰图片一步步涂成噪声，同时在噪声空间里立起了路标：每一点的分数都指出去噪的方向，Tweedie 恒等式担保这个方向就是最佳去噪，预测噪声和预测分数的网络只差一个缩放因子。可路标不是路程。真站在一张纯噪声面前，朝这个方向走一步之后呢？步长取多大、要不要加抖动、上一章"一千步只是切片"那扇门后面的连续世界又该怎么走？先对齐一个词：§9 讲过大模型的采样，是从词表分布里抽一个词；这一章的采样是同一件事的另一个尺度，从数据分布里走回一张图。两种用法是一个意思，都是从概率分布里抽一个实例，只是图片的分布没法直接抽，得靠反向过程间接实现。反向扩散就是这条间接的路，而随机性是这条路上必须保留的东西，不是能甩掉的误差。

## 反向 SDE：从噪声走回数据

前向加噪把清晰图片涂成噪声，反向要把噪声走回清晰图片，这一路需要两样东西。一样是方向：站在噪声空间的任意一点，得有人告诉你往哪走能靠近真实数据，这是上一章的分数函数。另一样是随机性：同一个噪声点可能来自多张不同的原始图片，确定性去噪只会走到"平均答案"；随机扰动让采样在合理的去噪方向上选择不同的路径，每次采样各走一条，单条轨迹的随机分支由此保住。

把这两样东西写进一个方程，是反向 SDE 的任务：分数提供方向（漂移项），布朗运动提供随机性（扩散项）。布朗运动是一路随机乱走的噪声过程，名字来自花粉颗粒在水里的无规则运动，前向加噪的连续版本就踩着它走。上一章结尾留过一句话：把一千步切到无穷细，就走进连续世界。现在兑现它——把离散加噪的步长切到无穷细，加噪规则就变成一条随机微分方程（行话 SDE），长这样：

`dX_t = f_t(X_t)dt + g_t dB_t`

记号一行行认。f 是漂移，定向推手，决定把变量往哪推；g 是扩散系数，决定噪声注入的强度。此 f 非 §2 的损失 f(x)，此 g 非 §3 的约束函数 g，撞了号，各归各的。dB_t 是布朗运动在无穷小时间里的增量，一抖。dB 这类微分记号一行带过：把它想成"一小步的随机位移"就够用了。这个方程从 0（干净数据）走到终点时刻 T（纯噪声）：§3 那个 T 是温度，管松紧；这个 T 是时间，管走到头。

Anderson 定理给出它的时间反演，反向 SDE：

`dY_s = [−f_{T−s}(Y_s) + g²_{T−s}·s*_{T−s}(Y_s)]ds + g_{T−s} dB̃_s`

s* 是真实分数（上一章的主角：s_t(x) = ∇_x ln p_t(x)，密度增长最快的方向），B̃ 是反向布朗运动，持续注入的随机噪声；Y_s 是反向过程的状态，s 是反向时间，对齐见"两套时间，一张表"块。借上一章的滴墨画面看这台机器：前向 SDE 同时开着两台引擎，漂移是定向推手，把信号往某处推；扩散是随机晕染，把墨滴越晕越开。倒着走时，两台引擎的命运不一样。漂移是定向的，把符号翻过来就能抵消，像把一段拍好的轨迹倒放。扩散却没有自动倒放：墨滴一旦晕开，绝不会自己聚回来，时间倒流也不会让散开的墨自动收拢。想让它归位，必须外加一股主动的收拢力，这正是中间那项 g²s* 的角色：分数指向密度升高的方向（临界点为零），沿它走就是逆着晕开的方向、往墨最浓处爬，把摊开的概率质量重新聚拢。三项里剩下的 g dB̃，是延续下来的随机扰动。

所以 Anderson 定理说的是：翻转漂移，补一项分数收拢力，不多不少，恰好让反向轨迹的分布严格等于前向过程倒着看。反向 SDE = 逆漂移 + 分数修正 + 随机扰动，三项各司其职。

分数项的系数当场问清：为什么是 g²，不是 g，也不是 ½g²？第一个为什么好答：布朗运动的方差与时间成正比（Var(g dB_t) = g²dt），扩散对密度的影响是二阶效应，正比于 g² 而非 g。第二个为什么牵扯一个新工具，完整的答在"g² 的第二个为什么"块里；先拿结论：那个 ½ 是 Itô 微积分里的"半修正"，前向方程的密度视角里它出现一次，反演时分数修正必须抵消完整的扩散效应，所以系数翻倍成 g²。

<details>
<summary>两套时间，一张表对齐（两套时间的对账表）</summary>

这一章有两套时间变量，先对齐再上路。

前向时间 t：从 0（干净数据 X_0）走到 T（纯噪声 X_T），前向 SDE 用它。反向时间 s：从 0（纯噪声）走到 T（干净数据），反向 SDE 用它。两者互为倒影：s = T − t。状态变量也跟着改名：前向写作 X_t，反向写作 Y_s——同一条轨迹在两个时间坐标下的两个名字，Y_s = X_{T−s}。切坐标最容易切错，切错一步，后面的数字全错：每次把方程从 Y_s 换回 x_t，错了都当场露馅。

DDPM 论文用前向离散索引 t 记离散步（采样时 t 从 T 数回 0），NCSN 用噪声水平序号 i。有些文献的离散索引写作 k，这套读物不取：k 在 §8 是奇异值截断的项数、在 §9 是 top-k 的候选个数，再立一个要打架。

通式逐项对账：

| 符号 | 含义 |
| --- | --- |
| Y_s | 反向过程在时刻 s 的状态（s=0 纯噪声，s=T 干净数据） |
| −f_{T−s} | 前向漂移的逆：逆转确定性部分 |
| g²_{T−s}·s* | 分数修正项：指向数据密集区 |
| dB̃_s | 反向布朗运动：新的随机噪声 |

</details>

<details>
<summary>g² 的第二个为什么：半修正去了哪里</summary>

第二个为什么要用一个新工具：Fokker-Planck 方程，SDE 的"密度视角"。上面的 SDE 追踪单条样本的轨迹，一个粒子怎么走；Fokker-Planck 追踪所有样本合成的概率密度 p_t 怎么随时间流动，整片云怎么变形。同一个过程，粒子视角对场视角，这里只借一条结论：前向扩散对密度的贡献，系数是 ½g²。

那这个 ½ 去哪了？它正是 Itô 微积分里的"半修正"（二次变差贡献的一半），前向的 Fokker-Planck 方程里有它。Anderson 定理做时间反演时，分数修正项必须抵消完整的扩散效应，不能只抵消一半，所以反向 SDE 里的系数是 g²，而不是 ½g²。

Fokker-Planck 里那个 ½，到 ODE 速度场里变成 ½g²；反向 SDE 里的 g² 是它的两倍。这个"两倍"不是巧合，T3 推概率流 ODE 时它会再来一次。

</details>

回看整条反向 SDE，未知的东西只有一样：s*，真实分数。f 和 g 是我们自己选的调度，B̃ 是标准布朗运动，都算不上秘密；只有分数依赖数据分布。而上一章的 Tweedie 恒等式已经把它和去噪接上了，所以只要知道分数，就能逆转。网络怎么把分数学到手，见 T3；全程把已训好的网络当黑箱用。

一个自然的误会在这里要道破：反向过程就是前向过程倒着放。不是。前向是 f dt + g dB，反向是 (−f + g²s)ds + g dB̃，中间多出来的分数修正项才是主角，漂移项翻个号只是配角。不信做个思想实验：把前向方程里的 dt 直接换成 −dt，却偷懒不加分数项，会怎样？结论先摆在这：少了分数项，反向 SDE 只是形式上倒放，密度演化的方向全错。多出来的这一项正是要学的对象，也是反向过程需要训练、前向过程无需训练的根本原因。

<details>
<summary>◌ 反事实推演：只翻号、不加分数项</summary>

以 VP 为例。前向方程 `dX = −½X dt + dB`，漂移把信号往 0 拉，噪声持续注入。把 dt 换成 −dt、不加分数修正项，方程变成 `dY = ½Y ds + dB̃`：漂移翻成了往外推的发散项，噪声却照样注入。一股力往外推、一股力接着搅浑，密度演化完全不匹配数据分布，轨迹既不收敛到数据、也不停在纯噪声，而是一路走向一个错误的分布。

从 Fokker-Planck 的密度视角看更清楚：分数项才是让反向密度演化与前向倒放严格对应的关键，它把熵增的加噪过程转成熵减的去噪过程。

</details>

## DDPM 与 NCSN：同一回事的两种写法

先走 DDPM 这一侧。VP 调度的前向方程（上一章立过，两种加噪时间表之一）是 `dX_t = −½X_t dt + dB_t`，f 和 g 分别是 −½X 和 1。代入通式，VP 反向 SDE 落在纸上只有一行：

`dY_s = [½Y_s + s*_{T−s}(Y_s)]ds + dB̃_s`

DDPM 论文里那条大名鼎鼎的采样公式（从噪声一步步走回图片的递推式）就是它的离散版，中间隔着四步不轻松的代数。四步骨架：离散化、代换、换时间坐标、对齐调度。

<details>
<summary>VP 到 DDPM：四步推导链</summary>

**第1步：Euler-Maruyama 离散化。** 把微分换成差分：ds 用步长 Δs 近似（步长记 Δs，免得和 §2 的学习率 η 打架），dB̃_s 用 √Δs·ε 近似（ε 每步从标准高斯新抽一个，就是前向加噪里那枚骰子；因为布朗运动的方差是 Δs，开方后乘回去）。一步更新：

`Y_{s+Δs} = Y_s + (½Y_s + s*_{T−s}(Y_s))Δs + √Δs·ε`

**第2步：Tweedie 代换。** 网络实际学的是预测噪声，不是预测分数，用上一章的等价关系 s* = −ε_θ/σ_t 把分数换成噪声（ε 这个记号 §7 章末三行见过：扩散模型预测的噪声向量；下标 θ 表示它来自网络。σ_t 是时刻 t 的噪声标准差，§2 高斯一族的记号，不是 §8 的奇异值）。

**第3步：时间坐标切换。** DDPM 论文用前向离散索引 t 记步数，令 t = T − s，则 Y_s = x_t；s 增加一步 Δs，对应 t 减少一步，所以 Y_{s+Δs} 写作 x_{t−1}。方程变成 x_{t−1} 用 x_t 表达的递推式。

**第4步：调度对齐。** DDPM 的离散调度用的还是上一章闭式跳步那套连乘记号 ᾱ_t = ∏α_i（第 t 步信号保留率 α_t = 1−β_t，噪声增量 β_t：不是 §7 的 β，RLHF 的 KL 系数），对应连续版本的 e^{−t}。三个替换把连续参数换成离散记号：Δs 换成 1−α_t（两边取对数得 Δs = ln(1/α_t)，步长小时 ln(1+x) ≈ x）；σ_t 换成 √(1−ᾱ_t)；再把三项各自合并成采样公式里的系数。

四步各管一件事：第1步把连续微分变差分，第2步把"分数"换成网络实际学的"噪声"，第3步把反向时间切回论文的离散索引，第4步把连续调度翻译成离散记账法。没有一步是顺手整理就能得到的。

</details>

四步走完，DDPM 采样公式落地（t 从 T 一路倒着数回 0，每步噪声更少一点）：

`x_{t−1} = (1/√α_t)(x_t − (1−α_t)/√(1−ᾱ_t)·ε_θ(x_t, t)) + σ_q·ε`

x 在这里是数据点，一幅图拉成的数串，不是 §2 那个待优化的参数；下标是步数。上一章"直接跳到第 t 步"在 VP 连续写法里的样子 a_t x_0 + σ_t ε（离散版就是闭式跳步）；到了 DDPM 这里，同一件事换成离散记账法。σ_q 要单独认：它特指每步新注入的采样噪声标准差，区别于前向加噪的标准差 √(1−ᾱ_t)——DDPM 论文里这两个量碰巧共用 σ 这个符号，容易混，这里分开叫。

系数虽多，拆开就是三个目的动作依次执行。这三个名字不是标准术语，是按每个动作的意图起的。

1. 拉向数据：括号里减掉网络预测的那部分噪声 ε_θ。减掉噪声，等价于朝数据密集区挪一步，减的方向正是分数指的方向，这是去噪的主干。
2. 复原尺度：整体乘 1/√α_t。前向每步把信号缩小 √α_t 倍，反向把它放大回来。别误会：这个系数不是工程师拍脑袋加的补偿，而是反向 SDE 离散化的代数产物，恰好带来"放大回来"的效果。
3. 保分支：加上 σ_q·ε，补一点新随机噪声。同一个 x_t 可能来自多张原图，随机项让每次采样走不同的合理路径，让同一起点走出不同的轨迹。

第4步的合并用的是一阶近似（ln(1/α_t) ≈ 1−α_t，1+½(1−α_t) ≈ 1/√α_t）。DDPM 论文的调度每步噪声增量大约在万分之一到百分之二之间（β 从 0.0001 线性升到 0.02），一阶展开的误差按 β²/8 估算，从十亿分之一量级（第一步）到十万分之五（最后一步），完全可以忽略。所以严格说，这条公式不是从反向 SDE"精确推出来"的，而是"用一阶近似定义"出来的算法。归属上，它仍然是 VP 反向 SDE 的一种离散化方案：严格性说的是推导过程，归属说的是框架位置，两件事不冲突。

再走 NCSN 这一侧，结构完全对称，VE 调度的 f = 0 还省掉几步代数。VE 前向方程是 `dX_t = dB_t`，代入通式，反向 SDE 只剩分数和噪声：

`dY_s = s*_{T−s}(Y_s)ds + dB̃_s`

离散化之后是 Langevin 采样公式（上一章的 Langevin 直觉，在这里有了正式形态）：

`x^{(i+1)} = x^{(i)} + δ_i·s_θ(x^{(i)}, σ_i) + √(2δ_i)·ε`

i 是噪声水平的序号，噪声水平从大到小排成退火序列，分数只关心"当前有多噪"这一件事，所以直接用噪声水平 σ 当索引。δ_i 是该噪声水平下的步长增量：δ 特指步长增量，α 特指信号保留比例，两个记号别串门。

这条公式比 DDPM 直白，只有两个目的动作。第一是拉向数据：沿分数 s_θ 走一步 δ_i，朝数据密集区挪——和 DDPM 的第一动作是同一件事，两条公式的去噪主干完全同构（ε 与 s 只差一个 −σ 因子，上一章的等价关系再立功）。第二是保分支：加上 √(2δ_i)·ε。这有个经典名字，Langevin 动力学：物理上是一颗粒子在势能场里受力滑向谷底、同时被热噪声不停撞击。对照 DDPM，它少了"复原尺度"这一动作：VE 调度信号不缩放，没有衰减需要补偿，自然省掉。

噪声系数值得单独说。字面离散化的系数是 √Δs，NCSN 论文却把它换成了 √(2Δs)：这不是推导出来的，是论文的策略选择，它想在每个噪声水平内多走几步做精修，让每一层的稳态分布对上目标。但 √2 这个数本身有数学必然性：在漂移恰好是分数的设定下，它是让稳态分布恰好等于目标分布的唯一选择，系数小了稳态偏集中（低估方差），大了偏铺开。

<details>
<summary>VE 到 NCSN：推导链与 √2 的来历</summary>

**第1步：字面离散化。** VE 反向 SDE 直接做 Euler-Maruyama，一步更新 `Y_{s+Δs} = Y_s + s*·Δs + √Δs·ε`，噪声系数是 √Δs。

**第2步之前：换成 Langevin 形式。** NCSN 没有停在这里，而是把噪声系数换成 √(2Δs)（策略动机与稳态论证在第4b步）。

**第2步：免代换。** NCSN 的网络直接输出分数 s_θ(x, σ)，不需要 Tweedie 代换——这是上一章"噪声与分数两套名字原来是一回事"的另一面：DDPM 选输出 ε，NCSN 选输出 s，两条路都通。

**第3步：噪声水平索引。** 不按论文里的整数步编号，改用噪声水平本身做索引，退火序列从大噪声走到小噪声，步长按噪声水平的平方分配：δ_i 正比于 σ_i²/σ_{L_σ}²，让高噪声用大步、低噪声用小步。

**第4a步：几何级数调度。** 噪声水平取几何级数，相邻两档成固定比例，越靠近小噪声越密：σ_i = σ_max·(σ_min/σ_max)^((i−1)/(L_σ−1))。原始 NCSN 论文取 σ_max = 1、σ_min = 0.01、共 10 档；后来的实现会换数，范围越拉越宽。几何级数在对数噪声尺度上均匀铺开，比线性调度覆盖得匀。

**第4b步：√2 的稳态论证。** Langevin 动力学的标准形式是 SDE `dx = ∇ln p dt + √2 dw`，它对应的 Fokker-Planck 方程是 ∂_t p = −∇·(p∇ln p) + ∇²p：第一项是漂移带来的聚集流，把密度往高概率区推；第二项是扩散带来的散开流。又有 ∇ln p = ∇p/p，两项恰好抵消，∂_t p = 0，p 成为稳态。这个抵消只在扩散系数等于 √2 时成立。VE 反向 SDE 不追求"稳态等于 p"——它只要在有限时间内跑到数据分布，字面离散化的 √Δs 就够；但 NCSN 的多层精修策略必须配 √2，才能让每层的稳态对上目标。

</details>

对照一看，NCSN 的 Langevin 采样与 DDPM 侧如出一辙：它也不是 VE 反向 SDE 的精确离散化，而是"一阶欧拉离散化 + Langevin 的 √2 因子 + 几何级数调度"这三件事的组合。

两条推导链摆完，结论可以落锤了：DDPM 和 NCSN 的推导结构完全对称，只是每一步的具体代数不同。它们不是两个模型，是一个模型的两种实现——同一反向 SDE 通式、不同调度、不同离散化，是同一棵树的两根枝。

| --- | --- | --- |
| 调度 | VP | VE |
| 前向 SDE | `dX = −½X dt + dB` | `dX = dB` |
| 反向 SDE | `dY = (½Y + s*)ds + dB̃` | `dY = s* ds + dB̃` |
| 离散化 | DDPM 采样公式 | Langevin 采样公式 |
| 网络输出 | ε_θ（预测噪声） | s_θ（预测分数） |
| 等价性 | ε_θ = −σ_t·s_θ（Tweedie） | 同左 |

觉得两条公式是两套独立推导？用上表的最后一行：两个网络输出只差一个缩放因子，去噪主干完全同构，把其中一个的参数化换算一下就是另一个（依据是上一章的 ε–s 等价关系）。调度也不是谁高谁低：VP 和 VE 只是两种不同的加噪时间表。

三层分清，全章不混。层次1，调度：选 f 和 g，只是选择。层次2，反向 SDE：Anderson 通式统一给出，调度只决定 f 和 g 取什么值。层次3，离散化：选数值方法，DDPM 采样公式和 Langevin 采样公式都只出现在这一层；T3 还会往这层添新成员，把随机项置零之后得到的 ODE（常微分方程，没有随机项的微分方程）求解器家族。三层正交：换调度不改变反向 SDE 的形式，换离散化方法不动前两层。

通式的漂移项 −f + g²s 还能再拆成两份：−f 是确定性输运，把被缩小的信号拉回来，VP 有这一项，VE 的 f = 0 所以没有；g²s 是分数修正，把信号拉向数据密集区，两条采样公式共享的"拉向数据"主干就是它。这解释了为什么 DDPM 的路径比 NCSN 直接：它多一项"拉回"。

<details>
<summary>◌ 一个注脚：教学版 VE 与实际 NCSN</summary>

对照表里 VE 的前向 SDE 写的是 `dX = dB`（g = 1，σ_t = √t），这是教学版。NCSN 实际用几何级数噪声水平，对应的 g 随 σ 变化，不是常数 1。但"同一反向 SDE 通式下的两种调度与离散化"这个结论仍然成立：几何级数只是换离散化的采样点，VP 和 VE 的区别在于漂移项的有无这一结构差异，而不只是网格参数怎么取。

## 随机性的必要

前向加噪是随机的，反向为什么不能确定性去噪？同一个噪声点对应多张可能原图，确定性去噪只会走到"平均答案"——这个直觉前面已经点过；现在算清它的账。随机性不是缺陷，是特征。

先排除一个近邻的误会：这个随机项不是离散化带来的数值误差，步数加密也不会把它"算没"。它是方程本身的成分，属于刚才说的层次2；数值误差是层次3 的事，两笔账别记混。

"随机性是必需的"和"去掉随机性质量不降"，两句话矛盾吗？不矛盾，它们说的是多样性的三种不同来源。三层摊开：

| 多样性层次 | 谁提供 | 去掉随机项的影响 |
| --- | --- | --- |
| 样本间多样性（不同起点生成不同样本） | 初始噪声的随机性 | 不受影响，起点随机就够了 |
| 单条轨迹的随机分支（同一起点走出不同路径） | 反向 SDE 的随机项 | 失去，轨迹变成确定的 |
| 单样本质量（最终图片好不好看） | 分数的准确性＋数值精度 | 实践中不受影响，多步下可比或略优 |

精确的说法是：样本间多样性由初始噪声保证，SDE 的随机性只影响轨迹分支。把随机项置零，同一个模型换不同的噪声起点，依然生成不同的猫。这个不对称性是 T3 拿掉随机项的底气。置零之后的采样器行话叫 DDIM：可复现确实是它的动机，代价也写在表里——单条轨迹的随机分支没了。二十步够不够快这笔账，连同它怎么跟训练对上口径，T3 一起算。笼统说"去掉随机性，多样性会相应降低"也不算错，但降的要说清是哪一层：按表，失去的是单条轨迹的随机分支，样本间多样性和单样本质量都不动。

## 动手：一步采样

该动手了。题面先定口径：这里用反向 SDE 的欧拉离散形式，而不是调度对齐后的 DDPM 采样公式——两者是同一棵树的两种写法，近似处理不同；选欧拉形式，是为了让漂移项和分数项的贡献可以直接看见。取同一个噪声点 x_t = [1.0, 0.5]，同一个学到的分数 s_θ = [−0.3, 0.4]，步长 Δs = 0.1，随机噪声 ε = [0.2, −0.1]。拿张纸，先猜三个部分里哪一项贡献最大，再动笔。

**VP（DDPM）一步**，f = −½X，所以逆漂移是 +½X：

```
x_{t−1} = x_t + Δs(½x_t + s_θ) + √Δs·ε
= [1.0, 0.5] + 0.1×([0.5, 0.25] + [−0.3, 0.4]) + √0.1×[0.2, −0.1]
= [1.0, 0.5] + [0.02, 0.065] + [0.063, −0.032]
= [1.083, 0.533]
```

三个部分的贡献一笔一笔对得上账：漂移项补偿收缩尺度，贡献 [0.05, 0.025]；分数修正贡献 [−0.03, 0.04]；随机噪声贡献 [0.063, −0.032]。三项加起来正好等于总增量 [0.083, 0.033]，一格不多一格不少。

**VE（Langevin）一步**，f = 0，没有逆漂移：

```
x^{(i+1)} = x^{(i)} + Δs·s_θ + √(2Δs)·ε
= [1.0, 0.5] + 0.1×[−0.3, 0.4] + √0.2×[0.2, −0.1]
= [1.0, 0.5] + [−0.03, 0.04] + [0.089, −0.045]
= [1.059, 0.495]
```

两种方法用了同一个分数，走了不同的路径：VP 多了一个补偿收缩的漂移贡献 [0.05, 0.025]，VE 没有；VE 的随机噪声更大，√(2Δs) ≈ 0.447 对 √Δs ≈ 0.316，多了四成，所以 VE 的路径更飘忽；这份差距每步都在累积，几百步下来，轨迹的散漫程度完全不同。

三道变式，算完正账再玩。ε 换成 [−0.2, 0.1] 再算一遍：DDPM 走到 [0.957, 0.597]，Langevin 走到 [0.881, 0.585]。步长缩到 0.01：噪声项缩到约三分之一（幅度是 √Δs 的账：[0.063, −0.032] 变 [0.02, −0.01]），漂移和分数的贡献各缩到十分之一——这就是"一阶"两个字的身价：步长缩到十分之一，分布层面的误差大约也缩到十分之一。回到原来的步长、把 ε 置零只走确定部分：DDPM 走到 [1.02, 0.565]，Langevin 走到 [0.97, 0.54]——少了随机项，同一个起点只此一条路，这正是 T3 要讲的确定性采样（ODE）在纸上的样子。

配套脚本（assets/T2-体验实验/one_step_sampling.py）把每个数做成断言，与你的纸笔答案对拍；正文里的显示值全部按"精确值一次舍入、再按显示值逐格重加"的工序核验过，两条链都闭合。一步只是机制演示：真实采样要成百上千步，步数怎么压、质量怎么保，是 T3 的账。

## 回望与下一章

收成一句话：知道了方向，噪声变回数据的路就是一条反向 SDE——分数当收拢力，随机性保轨迹分支，离散化之后变成 DDPM 或 NCSN 的采样公式，两个名字，同一棵树。

三题自查。

1. 反向 SDE 比"前向倒着放"多了哪一项？拿 VP 做反事实：把这项删掉、只把漂移翻号，轨迹会走向哪里？
2. DDPM 采样公式拆开是哪三个目的动作？"复原尺度"的系数是工程师拍脑袋加的补偿吗？
3. 三层多样性表里，随机项管的是哪一层？把它置零会失去什么、保住什么？

路修通了，可整条路都架在一个前提上：分数已知。这个方向是网络学出来的——怎么学，以及学好了怎么把一千步压到二十步，是支线下一章（T3）的两笔账。走完了破坏与逆转，下一章问：方向怎么学。
