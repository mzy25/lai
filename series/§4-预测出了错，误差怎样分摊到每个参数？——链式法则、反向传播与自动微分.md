# §4 预测出了错，误差怎样分摊到每个参数？——链式法则、反向传播与自动微分 ▽

分类用交叉熵、回归用均方误差，凭什么都合理？梯度怎么一层一层算回来？第一个答案是一句话：两种损失是同一个"最可能"框架的两个面孔。第二个是预测出了错，这笔误差账怎样一层一层分摊到每个参数头上。链式法则是分账的规矩，反向传播是执行的流程，自动微分是把流程交给机器。到这里，数学基础就齐了。

## 误差从哪来——损失函数

先把"凭什么"答掉。统一的框架叫**最大似然估计**：调整参数，让模型"最可能"生成你观测到的真实数据；数学上，这等价于最小化负对数似然。分类问题里，§3 已推过一遍：one-hot 标签下似然只剩正确类别那一项，取负对数，正是交叉熵 H(y,p)。回归问题里，§2 也推过：把预测误差想成高斯噪声，取负对数、扔掉与参数无关的常数，剩下的就是误差的平方，正式名叫**均方误差**，记号 `MSE = 1/2·(ŷ − y)²`。ŷ 读作 y-hat，模型对真实答案的猜测；y 还是那个真实答案，回归里它是一个数，分类里它是一串 0 和 1。

两类任务，两种损失，同出一个框架。预测一个数，叫回归；从几个候选里挑一个，叫分类。选损失，就是选你对世界的假设；选错损失，模型学不到正确的东西。损失一旦发出"差评"，信号怎样传回每个参数，是后面几节的事。

## 链式法则：复合函数的账

你开了一家小餐馆，客人吃了一口，皱眉说"味道不对"。这个"不对"的程度就是损失。从最终口味往前一道一道倒查：汤咸了，是盐放多了，还是上道工序传下来的汤底有问题？每个环节该负多少责任，行话叫梯度；反向传播就是这套倒查流程，从客人的一句"味道不对"，把责任精确分到每个环节：这道工序背三成，那道背七成。

倒查的工具是**链式法则**：函数套函数时，总效应等于每段局部效应的乘积。算一遍：`f(u) = u²`，`u(x) = 3x`，`df/dx = df/du·du/dx = 2u·3 = 18x`。x 变动一点，变化先乘 3 传到 u，再乘 2u 传到 f：每段只算自己门口的账；把各段的局部效应乘起来，就是总效应。

网络里要追的不是一个旋钮，而是成亿个参数。对它们逐个求"只许你动、其余全部按住"的导数，这个运算叫**偏导数**，记号 `∂`（读作 round）。全部参数装进一个总名单，记作 θ；说"对 θ 求梯度"，就是对名单里每个参数逐一求偏导，再拼回 §2 那个梯度 ∇f（下山走它的反方向）。

把网络画成一张**计算图**：每个节点是一种运算，每条边把数据递给下一个节点。**前向传播**时，数据从入口流到出口，得到预测；预测错了，责任从出口倒着流回去，沿路每个节点把自己这一段的局部导数乘上去，传给前一个节点。梯度流到的地方，就是责任被查到的地方。把这套思想系统化并推向普及的，是 Rumelhart、Hinton 和 Williams 1986 年的工作。

## 误差分回每个参数：反向传播

账要倒查，先得正着走一遍。练手用一个最小网络：两个输入（已做**特征缩放**：面积 200 平米除以 100 记成 2，房龄 3 年记成 3，x = [2, 3]），中间一层三个**隐藏神经元**，每个都是"先加权求和、再过激活函数"的最小单位。记号认下：W 是权重矩阵，W_ij 是第 i 个隐藏神经元对第 j 个输入的重视程度；b 是偏置，每个神经元的起点；z 是加权求和加偏置之后、还没过激活函数的分数（前面用它记输出层的分数，这里它记每一层的）；h 是过了激活函数的信号，筛选后的特征表示。

前向三步。第一步 `z = Wx + b`：W = [[1,2],[3,4],[5,6]]，b = [1,1,1]，W 的每一行与 x 做**点积**（对应位置相乘再相加），得 8、18、28，各加偏置 1，z = [9,19,29]。三个隐藏神经元分别收到信号 9、19、29。第二步 `h = ReLU(z)`：ReLU 是最常用的**激活函数**，一个单向阀门，正数放行、负数抹成零，后面讲它的导数与初始化；这里三个数全正，一个没死，h = [9,19,29]。第三步 `ŷ = W_out·h + c`：W_out = [1,2,3]（输出层权重，一个向量），c = 1，ŷ = 9 + 38 + 87 + 1 = 135。

网络猜 135，真实值是 10：差 125，预测是真实值的 13.5 倍，严重偏高。这就是那笔"顾客投诉"，倒查从它开始。形状也顺手看清：两个数进，三个 z、三个 h，最后收成一个数；这笔维度账，反向时倒着核对一遍。动手倒查之前先猜一笔：过 ReLU 之后，三个信号里谁的责任最大？大约差几倍？

损失取均方误差 `MSE = 1/2·(ŷ − y)²`。式子里那个 1/2 是工程上的方便：求导时平方会冒出系数 2，前置 1/2 刚好消掉，梯度公式因此干净；它不改变最优解的位置。

现在倒查。你最好拿张纸，跟我一起算。第一步，损失对 ŷ 的偏导 = ŷ − y = 135 − 10 = 125。含义：预测每往上抬 1，损失就涨 125，损失在喊"快把预测往下调"。第二步，损失对 h 的偏导 = 125 × [1,2,3]：三个隐藏神经元对预测的影响力是 1、2、3，第三个说话最有分量。

第三步，穿过 ReLU：导数规则"正 1 负 0"，放行段坡度 1、抹零段坡度 0；要是某个分数是负的，这一段会把它抹成 0，坡度跟着归零——下一步它就不再欠账；本例三个 z 全正，导数是 [1,1,1]；**逐元素相乘**，记号 `⊙`（行话 Hadamard 积：两个向量对应位置各乘各的），损失对 z 的偏导 = 125 × [1,2,3] ⊙ [1,1,1] = [125,250,375]。

第四步，分到每条连线：z 的每个分量，都是 W 的一行与 x 的点积加偏置，所以 z 对 W 的偏导就是 x。**外积**上场：点积是行乘列得一个数，外积是列乘行得一张矩阵，转置就是把横排的竖成列。损失对 W 的偏导 = [125,250,375] 转置 × [2,3] = [[250,375],[500,750],[750,1125]]，三行两列，恰好是 W 的形状。

盯住 375，三个 z 里最大的责任。它为什么最大？375 = 125 × 3 × 1：末端误差 125，乘它在输出层的连线权重——W_out 的第三个分量，等于 3（ReLU 导数恰为 1）。信号值 h₃ = 29 看起来最大，但它完全没有进入 375。两句话分清两条路：损失对 z 的偏导问"这个神经元该为误差负多少责"，看输出权重 W_out；损失对 W_out 的偏导问"这条连线该负多少责"，看它传递的信号 h。两条路，各用各的量。

剩下的参数顺手分完：损失对 W_out 的偏导 = 125 × [9,19,29] = [1125, 2375, 3625]，损失对 c 的偏导 = 125；偏置的系数是 1，损失对 b 的偏导就是损失对 z 的偏导：[125,250,375]。责任的形状永远和参数的形状一致：对标量是数，对向量是向量，对矩阵是矩阵。再记一件事：分类网络的末端梯度是 p − y，回归的是 ŷ − y = 125；形式不同，传播机制一模一样。"顾客差评"的初始信号怎样翻译成每一层、每一个参数的具体整改建议，就是这条链。g_t 就是这一步拿到的梯度。

反向传播的本质是逐段追责：把"损失对参数多敏感"拆成一串小账，每层只算自己门口的局部导数，乘以上游传来的责任。餐馆里也一样，每道工序只需告诉上一道"你传给我的东西影响了我这边几成产出"。局部通信，全局协调：深度网络的训练因此才成为可能。

W 做的是线性变换；任何线性变换都能拆成"旋转或反射、沿轴拉伸、再旋转或反射"三步，§8 拆矩阵要用这个事实。

## 激活函数的梯度与初始化

先加权求和只是一步直线，激活函数负责把直线折弯——不然叠多少层，等效的还是一层。最小网络用的 ReLU，是过去十年深度网络的默认选择；它的导数决定梯度能不能传回去，初始化决定信号一开始稳不稳。

ReLU 的导数在正数区恒等于 1：1 乘任何数还是那个数，误差信号穿过多少层都不打折。它的近亲 **Sigmoid** 把任意数压进 0 到 1，导数最大只有 0.25；梯度每过一层就乘一个不超过 0.25 的数，就算每层都拿到这个最大值，10 层之后也要乘 0.25¹⁰ ≈ 10⁻⁶。前层几乎收不到误差信号，整个网络几乎不再更新，这叫**梯度消失**，是深层网络的常见病。

ReLU 也有自己的毛病：一个神经元若一直收到负信号，输出是 0、梯度也是 0，权重永远不被更新，就成了**死神经元**；若它对每个训练样本都输出零，就是永久死亡，输入分布变了才可能复活，而把它推到这一步，初始化与学习率都有责任。好的初始化能防住一部分。ReLU 的变体 Leaky ReLU 给负数留一条小缝，让梯度有条窄路可走，这种死亡几乎被消除。

现代激活与归一化的做法见 §5 的 Block；这里只留反传需要的导数与初始化。

初始化是训练开始前的事：权重要取成小的随机数，取多大很有讲究，目标是一句话：让每一层输出信号的方差大致等于输入信号的方差。**Xavier 初始化**为 Sigmoid、Tanh 类设计，公式 `W ~ U(±√(6/(n_in + n_out)))`，n_in、n_out 是连线两端的神经元数：连接越多，每个权重的幅度越小。用 ReLU 的网络换 **Kaiming 初始化**：`W ~ N(0, 2/n_in)`，方差乘 2，补偿 ReLU 把负数置零造成的二阶矩减半（前提：信号关于 0 对称）。好的初始化让信号刚好平稳流动，这是训练深度网络最容易被忽视的第一步。

## 自动微分：计算图加节点级微分

四步手算，十三份责任。真实网络成亿参数，人手算不过来，也不必。**自动微分**一句话：计算图加节点级微分。框架把前向计算自动建成计算图，每个节点只需回答一个本地问题——我对输入的局部导数是多少？不必知道全网结构。它既不像符号微分那样把公式层层硬展开（表达式会膨胀到没法看），也不像数值梯度那样逐个测量（贵到不能用）：每个节点只存一行局部导数，图上走一遍，得到的就是精确答案。反向时，每个节点算出局部导数，乘以上游传来的责任，交给下一站：还是那家餐馆，每道工序只算自己门口的一段账。

分叉处有个细节，手算一次最明白。设 f = x·y + sin(x)，x = 2，y = 3。前向：a = x·y = 6，b = sin(x) ≈ 0.909，f = 6.909。反向：f 对 a、b 的偏导都是 1；a 对 x 的偏导是 y = 3，b 对 x 的偏导是 cos(x) ≈ −0.416。关键是 x 有两条路通向 f——一条经 a、一条经 b——两条路的责任相加：f 对 x 的偏导 = 3 + (−0.416) = 2.584，和直接求导 y + cos(x) = 2.584 对得上。

模式上还有选择：从输入往输出逐层求导叫**前向模式**，适合输入少、输出多；从输出往输入倒着传叫**反向模式**，适合输入多、输出少。深度学习正是后者：上亿级参数，输出只有一个标量损失，反向模式因此是绝对主流。数量账也记一笔：反向传播的算量约是前向的两倍，加在一起，一次训练步约等于三次前向。

三个误解，逐一说清。其一，"反向传播就是反向的前向"：两者走的是同一张计算图，装的东西完全不同：前向装数据、反向装责任；数据真倒着传，网络除了浪费电什么也学不到。其二，"梯度下降就是反向传播"：怎么算与怎么走是两件事，先把它们分清。反向传播负责算账，梯度下降负责走路：更新那一行里，"损失对 W 的偏导"是反向传播算出来的，减号和学习率 η 是梯度下降的事，一个导航，一个迈步，导航不迈步，迈步的不导航。其三，"梯度消失就是梯度变成零，只是某一类网络的专利"：任何深层网络的梯度都是一长串乘法，每层激活函数的导数、每个权重矩阵都是乘数；绝大多数乘数小于 1，连乘就指数级衰减，传到最前层跟零没有本质区别，乘数普遍偏大则是**梯度爆炸**。

## 动手：MLP 全推＋梯度检查

数学墙三块砖砌完了，该到验收的里程碑了：**MLP**（多层感知机，最小的一种神经网络）**全推**——前向反向全部手算一遍——加**梯度检查**，第 6 周末验收。预置笔记本（`assets/§4-体验实验/预置笔记本.ipynb`；§0.3 的 Colab 路线）里有一个微型网络：输入 3 个数、隐藏层 4 个神经元、输出 2 类，共 26 个参数。它先逐行写出前向传播，再逐行写出反向传播，每个参数的责任都用手推公式算出来；然后请出笨办法对答案：**数值梯度**，行话有限差分，把每个参数轻轻拨动一下，前后各算一次损失，损失的差除以拨动的量，就是斜率的直接测量，完全不靠求导公式。手推与测量逐参数对账，相对误差全部小于 1/100000 才算通过。

真实跑出来的结果：26 个参数全部通过，最大相对误差 `4.632e-11`，比合格线小了 5 个数量级还多，手推的链式法则和机器暴力测量的斜率，前 8 位小数完全一致。

笔记本里还留着一个结构性痕迹：输出层偏置的两个梯度互为相反数，0.593 与 −0.593。Softmax 的两个概率之和恒为 1，正确类别涨多少，错误类别就跌多少，这正是 §3 那个 p − y 的形状。它的隐藏层用 tanh（把任意实数压进 −1 到 1 的激活函数）、损失用交叉熵——激活与损失换了，分账的流程一个数都没改。

这道关为什么必过：梯度实现里的 bug 极难肉眼发现，链式法则某一步漏一个转置，模型照常跑，只是永远训不好；数值梯度慢得诚实，所以能当裁判。账也摆在这：26 个参数要量 52 次前向，上亿参数的网络要量两亿次，贵到不能拿它训练，只配当裁判。

验收有两件。合上正文、离开笔记本，把小网络从头推一遍：前向的 9、19、29、135，反向的 125、[125,250,375]、那张外积矩阵。再打开笔记本，看 26 个参数的梯度检查判 PASS。第 6 周末完成这两件，就迎来巩固半周：不做新内容，只重跑脚本、重推一遍。过了这一关，才进 §5。

## 回望与下一章
