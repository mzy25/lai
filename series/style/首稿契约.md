# 首稿契约（series v1）

> 目标：第一稿就成立，扫描器只做兜底。  
> 用法：动笔前逐条确认；写完按「首稿自检」过一遍；返工先查缺失契约，不先改词。

## 一、八条契约

1. **读者状态**：用一句“读前已知什么、读后能做什么”写下来。
2. **本节承诺**：这一节只解决一个问题，用问句或断言句说清。
3. **段落职责**：每段一个职责；同职责合并，多职责拆开。
4. **信息顺序**：先旧后新、先整体后局部、先断言后证据再意义。
5. **句子动作**：一句一个动作；主语是动作发出者；动词具体。
6. **术语落点**：新词先给全称、核心思想、为什么需要，再使用。
7. **断言强度**：定理/经验/作者判断分清；强断言带证据或限定。
8. **过渡内生**：用“解决了 A，但留下 B”推进，不报幕、不总结编排。

八条有一格填不出，说明这段还没想清楚；先补契约，不先写正文。

## 二、句子配方

| 目的 | 配方 |
|---|---|
| 定义 | `X（全称）= 属 + 种差；它用来…` |
| 机制 | `A 作用于 B，产生 C；因此…` |
| 公式 | `要算 X；公式是…；其中…；它说…` |
| 对比 | `A 做…；B 做…；差别在…` |
| 例子 | `取…；算…；得到…；这说明…` |
| 限制 | `这在…成立；超出…就…` |
| 过渡 | `上一节解决了 A；但 B 仍未解；下一节用 C…` |
| 收束 | `一句话：…；下一章要问…` |

句子删掉修饰后，主谓宾还在吗？在，句子成立；不在，重写主句。

## 三、段落展开

- **断言段**：主题句（具体对象+动作）→ 证据（公式/数字/例子/引用）→ 意义（读者能判断什么）。
- **定义段**：读者缺这个词会怎样 → 全称 + 核心思想 → 形式定义/记号动机 → 最小例子。
- **推导段**：目标 → 完整公式全景 → 分步（一步一个操作）→ 白话解读与边界。
- **对比段**：A 的做法与代价 → B 的做法与代价 → 同一维度的差别 → 选择判据。
- **过渡段**：上一节解决了什么 → 留下的具体问题 → 下一节用什么工具。
- **章末回顾**：先给知识性结论，再给下一章问题；不写“收成一句话”“三题自查”“整章的账收拢”等体例声明。

## 四、首稿自检

1. **朗读**：出声读 2–3 段；哪里绊住，哪里重写。
2. **反向提纲**：每段一句话写职责；同职责合并，多职责拆开。
3. **读者复述**：遮住正文，能否说出“本节解决了什么、留下什么”？
4. **术语回放**：新词是否使用前落地？旧词是否一物一名？
5. **断言称重**：最强的一句有证据吗？没有就降调或补证。
6. **停手**：六条都过就停；继续润色让句子变硬、变长、变绕，就回退。

## 五、返工诊断

| 症状 | 更可能缺的是 | 生成时怎么修 |
|---|---|---|
| 看不懂 | 读者状态/术语落点 | 补场景或先定义再使用 |
| 一段很长 | 段落多职责 | 一段只留一个动作，其余拆段 |
| 像翻译 | 主语缺失/名词化 | 找回动作发出者，用动词开头 |
| 像清单 | 没有问题链 | 用“解决 A→留下 B→用 C”重排 |
| 不可信 | 证据/限定缺失 | 补来源、条件或降为作者判断 |
| 越改越差 | 过度修饰 | 回到契约，删掉后加的限定 |

## 六、只保留三类硬红线

1. **不可逆文件损伤**：大文件 cat 后写回、转义翻倍、锚点不唯一。
2. **事实虚构**：编造来源、数字、引文、作者/年份。
3. **构建损坏**：手改 `dist`、绕过门禁、提交半成品。

其余失败模式只作查阅，不进入首稿主路径。
